# Security Policy

## Supported Versions

We release patches for security vulnerabilities for the following versions:

| Version | Supported          |
| ------- | ------------------ |
| latest  | :white_check_mark: |

## Reporting a Vulnerability

If you discover a security vulnerability, please do the following:

1. **Do not** open a public issue
2. Email the maintainers at security@pierogicoin.example (replace with actual email)
3. Include the following information:
   - Description of the vulnerability
   - Steps to reproduce
   - Potential impact
   - Suggested fix (if any)

We will acknowledge receipt of your vulnerability report within 48 hours and send a more detailed response within 7 days indicating the next steps in handling your report.

After the initial reply, we will keep you informed of the progress towards a fix and announcement. We may ask for additional information or guidance.

## Disclosure Policy

- We will confirm the vulnerability and determine its impact
- We will release a fix as soon as possible
- We will credit you for the discovery (unless you prefer to remain anonymous)

Thank you for helping keep PierogiCoin NFC secure!
