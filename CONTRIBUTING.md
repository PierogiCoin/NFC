# Contributing to PierogiCoin NFC

Thank you for your interest in contributing to the PierogiCoin NFC library!

## Getting Started

1. Fork the repository
2. Clone your fork: `git clone https://github.com/YOUR_USERNAME/NFC.git`
3. Create a new branch: `git checkout -b feature/your-feature-name`
4. Install dependencies: `npm install`

## Development Workflow

1. Make your changes
2. Run tests: `npm test`
3. Run linter: `npm run lint`
4. Run type check: `npm run typecheck`
5. Commit your changes using conventional commits (see below)
6. Push to your fork and submit a pull request

## Conventional Commits

We use conventional commits for clear commit history:

- `feat:` - New feature
- `fix:` - Bug fix
- `docs:` - Documentation changes
- `chore:` - Maintenance tasks
- `test:` - Adding or updating tests
- `refactor:` - Code refactoring

Example: `feat: add support for NTAG215 tags`

## Code Style

- Follow the existing code style
- Run `npm run lint` before committing
- All code must pass TypeScript strict checks

## Testing

- Write tests for new features
- Ensure all tests pass before submitting PR
- Aim for high code coverage

## Pull Request Process

1. Update documentation if needed
2. Ensure all tests and checks pass
3. Reference any related issues
4. Wait for review from maintainers

Thank you for contributing!
